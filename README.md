### [MCP Weather Agent — Israel & USA](https://github.com/HodayaFridland/MCP-Server-with-Playwright)
**Python · MCP · Playwright · Gemini**
An LLM agent that exposes weather tools over the Model Context Protocol. One MCP server automates a live browser with Playwright to retrieve forecasts from an Israeli weather service (RAG-style); a second integrates the official U.S. National Weather Service API for forecasts and alerts. The model autonomously decides which tools to call and in what order, then responds in natural Hebrew or English.

### [RAG over AI Coding-Tool Documentation](https://github.com/HodayaFridland/RAG-with-LlamaIndex)
**Python · LlamaIndex · ChromaDB · Cohere**
A Retrieval-Augmented Generation system that answers questions about the Markdown documentation produced by AI coding tools (Claude Code, GitHub Copilot). Built as an event-driven workflow that combines semantic search and reranking for open-ended queries with an LLM router that switches to structured JSON lookups for list-style questions ("all decisions", "all warnings"). Bilingual (Hebrew/English), with multilingual embeddings and hallucination-guarded prompting.
